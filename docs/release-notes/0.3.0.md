**新增按「策略组 + 域名」记账的流量统计脚本；当日统计的落盘从每分钟一次降到每 10 分钟一次，闪存不再被磨。**

## 本版内容

**流量统计**

- 新增 `openwrt/traffic-stats.sh`（cron 每分钟采样一次）—— 按「命中的策略组 + 域名」累计上下行字节，落到 `/etc/ShellCrash/stats/YYYY-MM-DD.tsv`，只留 31 天。机场流量被谁吃了、公共池承载了多少，从此可以按站点/组归因（nlbwmon 只能按 LAN 主机记账）。常驻 0、峰值内存 1.3 MB；已知偏差：两次采样之间开完就关的短连接会漏计，总量仍以 nlbwmon 为准。
- 修复 同脚本三处 —— 控制端口 / 目录改回「环境变量 → device.conf → 默认值」的加载顺序（原来写死 9999）；secret 与 guardian 同源读 `ShellCrash.cfg`（原来从 config.yaml 抠，带引号会鉴权失败）；首见连接只记种子不再把建立以来的字节一次性计入（核心重启后不再虚高）。

**闪存**

- 优化 落盘节拍 —— 当日 tsv 从「每分钟全量重写」（1440 次/天）改为差值攒进 tmpfs 缓冲、默认每 10 分钟聚合落盘（≤144 次/天，`STATS_FLUSH_MIN=0` 可退回逐分钟）。tsv 格式与统计口径不变；重启丢失窗口从 ≤1 分钟变为 ≤1 个落盘间隔。

**仓库**

- `check-secrets.py` / `check-docs.py` 同步系列仓已修的守卫漏报与误报；本仓分叉差异保留。
