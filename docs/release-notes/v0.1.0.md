## 本版内容

**openwrt/ 设备侧**

- 新增 网络守护 `guardian.sh` —— 每 5 分钟巡检一次：代理核心假死拉起、出口策略组被改坏则复原、
  nft 表掉了则补载、代理没真起来则重生成配置。只做自愈动作，**不删防火墙链、不重启设备、不改订阅**。
- 新增 离线恢复 `recover-now.sh` —— 「连上了 WiFi 但没网」时成套救回：
  清洗 fake-ip 过滤文件、摘掉 DNS 劫持、重生成配置、重新加载 nft 表、重载防火墙、恢复 crontab。
- 新增 开机自启模板 `rc.local` —— 建 `/tmp` 运行时目录（`/tmp` 是内存盘）、
  加载 nft 表、兜底重建 `/var` 下的运行时目录（`/var` 是指向 `tmp` 的软链）。
- 新增 ShellCrash 补丁恢复 `post-sc-update.sh` —— 官方脚本更新会冲掉本地打补丁的
  `starts/` 脚本，这一步把它们恢复回来。
- 新增 设备配置 `conf/device.conf.example` —— 节点名、策略组名、nft 表路径都在这里；
  读取顺序是「环境变量 → 配置文件 → 占位符默认值」。

**mihomo/ 控制面**

- 新增 规则审计器 `rule_audit.py` —— 算清楚「声明的分组」和「实际命中的分组」是不是同一个，
  哪些规则被靠前的宽泛规则遮蔽了。
- 新增 控制 API 客户端库 `mihomo_api.py` —— 走原生 IPv6、带重试、能解 chunked。
- 新增 实时日志 `mihomo_log.py`、增量抓日志 `capture_live.py`。
- 新增 节点延迟 `latency_probe.py` —— 策略组与节点的握手延迟。
- 新增 规则流式扫描 `scan_rules.py`。

**cdn/ 站点侧**

- 新增 CDN 连通性 `qq_cdn_probe.py` —— 把 DNS / TCP / TLS / HTTP 四段分开计时。
- 新增 DNS 路径 `qq_dns_path.py`、域名归类 `qq_domain_classify.py`、规则命中 `qq_rule_probe.py`。
- 新增 QUIC 能力探测 `quic_probe.py`。

**其它**

- 新增 文档自检 `tools/check-docs.py` —— 把「每篇必须有引言块、索引唯一、孤儿零容忍」这些
  写在文档里的规则变成 CI 里能跑的检查。
- 新增 CI —— shell / python 语法检查 + 文档自检 + **明文凭据扫描**。
- 调整 仓库 —— 文档自检跳过本地 `.work/` 与 `.codegraph/`；清理一次性生成产物。

---

需要 OpenWrt + ShellCrash（或任何 mihomo 内核的部署）。
`openwrt/` 的脚本会直接改路由器状态，执行前请先看
[架构说明](https://github.com/MVennn/OpenwrtOpsToolkit/blob/main/docs/ARCHITECTURE.md) 的「会改什么」一节。

---

> 风险提示：本仓库的脚本会直接修改路由器的系统状态（重启服务、重载防火墙、改 crontab、
> 切换代理策略组）；执行前请确认已备份。本仓不存放任何凭据，mihomo 的 secret 走
> `MIHOMO_SECRET` 环境变量；设备相关的值在 `openwrt/conf/device.conf`（不入库）。
> 位置索引见 [凭据与安全须知](https://github.com/MVennn/OpenwrtOpsToolkit/blob/main/docs/SECRETS.md)。
