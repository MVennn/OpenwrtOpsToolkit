## 本版内容

**流量统计**

- 新增 openwrt/traffic-stats.sh --summary —— 把 stats 目录下所有日文件合成一张账：机场出口 / 直连 / 兜底三分类，再给按组合计前 15 与域名前 20；只看单日的 --report 答不了跨天占比
- 调整 openwrt/traffic-stats.sh 分账口径 —— 组名可用 STATS_AIRPORT_GROUPS / STATS_DIRECT_GROUPS 覆盖，默认是一份通用占位口径，换机场不用改脚本
- 调整 openwrt/traffic-stats.sh 行为边界 —— --summary 只读日文件：不采样、不落盘、不写状态；--report 与攒批间隔一行未动

**大流量守卫**

- 修复 openwrt/bulk-guard.sh 空闲计时 —— 状态里没有 last_moving 时不再当 0 算，过去会得出「机场已空闲 29898910 分钟」并在机场与公共池之间来回切组
- 修复 openwrt/bulk-guard.sh 切换机场 —— 切过去那一刻补记 last_moving，回切空闲从这次切换起算，不再沿用上一个会话的时间戳
- 调整 openwrt/bulk-guard.sh 空闲阈值 —— 新增 BULK_MIN_BPS 可覆盖探测阈值，默认仍是 800000 bytes/s
- 调整 openwrt/conf/device.conf.example —— 补 BULK_MIN_BPS 与 BULK_RETURN_COOLDOWN 的取值样例与余量说明

**升级后校验**

- 修复 openwrt/post-sc-update.sh 内核校验 —— 按 CrashCore.upx → CrashCore.raw → 运行时软链顺序找第一个可执行内核再跑 -t；只有 upx 的设备不再静默跳过校验、日志照样写「验收完成」
- 调整 openwrt/post-sc-update.sh 覆盖方式 —— CORE_BIN 显式指定仍优先；三种内核都不在时显式告警，不留假绿

**文档**

- 新增 docs/PITFALLS.md P45、P46 —— 状态文件缺键取 0 当兜底、升级验收写死 CrashCore.raw 的机制与红线
- 调整 docs/TROUBLESHOOTING.md §16、§17 —— 流量统计数字不对先看 /tmp 缓冲再看日文件；升级后验收没跑 -t 的排查步骤与可直接粘的命令

- 调整 docs/TOOLS.md、openwrt/README.md —— 工具表与部署说明补 --summary 与 BULK_MIN_BPS
- 调整 README.md「已验证环境」 —— 设备 mihomo 当前值改为 v1.19.33
- 修复 文档口径 —— 版本号指针、shebang 路径、release-notes 索引、上游链接与凭据占位写法统一；仓内 memories/ 改为 dsh-mnemon 正本
