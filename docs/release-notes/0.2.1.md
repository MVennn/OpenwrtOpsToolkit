## 本版内容

**设备侧**

- 修复 离线恢复的 DNS 劫持摘除 —— 表名配置原来是空格串，`nft` 缺 family 时默认查 ip 族，inet 表永远删不掉；改为 `family:表名` 成对解析。
- 修复 恢复脚本的 WAN 诊断 —— BusyBox 的 `ip` 没有 `-brief`，不再因此误报「WAN 没地址」并触发 `ifup wan`。
- 修复 端口就绪判断 —— 不再用子串匹配（1053 会命中 10530）。
- 修复 出口健康探测 —— 同时看 HTTP 状态码，节点被封时的「快速失败」不再被判健康。
- 修复 切组请求 —— 节点名含引号 / 反斜杠 / `%` / `#` / `?` 时不再被控制 API 拒绝。
- 修复 守卫启动告警 —— 读不到 secret 时明确报错，不再静默失效。
- 修复 ShellCrash 更新后的验收统计 —— 分组数与规则数按 YAML 段定界统计，不再把 proxies 条目算进分组数。

**诊断工具**

- 修复 `mihomo_api.py` —— `/rules` 解包 `{"rules":[...]}`，`rulestats` 不再崩溃。
- 修复 规则审计 —— 缺 proxies.json 时不再全绿，并声明模拟范围。
- 修复 域名归类 —— 锚定完整域名，父域 / 兄弟域的日志不再互相污染。
- 修复 CDN 探测 —— 处理 DNS 压缩指针；HTTP 阶段异常不再误标成 TLS。

**仓库**

- 修复 密钥扫描 —— 本机路径只豁免命中片段；git 异常时不再「扫描 0 个文件通过」。
- 文档 —— `device.conf.example` 补 `PATCH_SPEC` 说明。
