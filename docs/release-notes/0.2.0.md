**大流量守卫改为按真实吞吐轮换：公共池跑不满先换节点、再切机场，机场停留到期自动回切。**

## 本版内容

**设备侧**

- 调整 大流量守卫 —— 活跃连接按 connection id 求正增量之和；探测跑满超时但收到数据时按实测速率算慢；确认为慢后先在公共池内按吞吐缓存换节点（每会话最多 2 个），再切机场；机场停留冷却后自动回切公共池并钉住吞吐最好的节点；新增钉住节点健康检查与实例锁。cron 从 `*/10` 改为 `*/3`。
- 修复 出口劣化判定 —— 两次探测取较慢那次，不再多除 2（此前阈值被压低一半）。
- 修复 静默回退自愈 —— 组名检查改用 `grep -F`，组名含 `[` / `*` / `.` 时不再误判并触发 hotupdate。
- 修复 离线恢复 `check` 模式 —— 只诊断，不再改写 fake-ip 过滤文件。
- 修复 状态文件写入 —— 节点名含 `|` 时不再静默失败。

**诊断工具**

- 修复 CDN 连通性 —— DNS 查询按标签编码（此前所有域名都回 NXDOMAIN），DNS / TCP / TLS / HTTP 四段耗时真正可用；HTTP 状态行改为读到响应头结束。
- 修复 规则审计 —— `findings.json` 跟报告同目录，不再写脏当前工作区。

**仓库**

- 新增 Issue 表单；文档自检与凭据扫描覆盖到 `cdn/` 与 `mihomo/`。
